# Production Sanitation — Artifact Classification

**Project TITAN — Production Sanitation & Commercial Readiness, Phase 2**
**Every category below is classified against two axes**: a disposition (KEEP / ARCHIVE / DELETE /
**UNKNOWN**) and a type (PRODUCTION / SOURCE / TEST / DOCUMENTATION / TEMPORARY / GENERATED).
**UNKNOWN is never paired with DELETE or ARCHIVE** — per this effort's own absolute rule, an
unresolved classification defaults to KEEP until its purpose is proven, full stop.
