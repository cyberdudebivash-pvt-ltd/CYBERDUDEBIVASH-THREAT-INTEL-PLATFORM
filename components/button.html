Component Reference

Button System

Primary / Secondary — as used for CTA pairs (e.g. "GET PRO ACCESS" + "Book a Demo")

Ghost / Outline — lower-emphasis actions (secondary nav links styled as buttons, filter toggles)

Danger / Success — destructive and confirmatory actions

Icon button — square, single-glyph actions (close, menu, copy-to-clipboard)

Disabled state — apply the disabled attribute (preferred) or .sapx-btn-disabled for non-<button> elements

Book a Live Demo

Loading state — label is visually hidden behind a spinner; keep accessible text via aria-busy + a visually-hidden status

Focus-visible — tab to a button to see the token-driven two-layer focus ring (--sapx-focus-ring)
