Default Spacing

.sapx-section

The default section wrapper. Use this for most marketing page sections — feature grids, integration lists, testimonials. Pair with a kicker / heading / description group like this one for a consistent section intro pattern across every page.

Compact Spacing

.sapx-section-sm

Reduced top/bottom padding for sections that should read as closely related to their neighbor rather than a fully separate page block.

Alternate Background

.sapx-section-alt

Adds --sapx-color-bg-surface as a background, creating a subtle band of visual separation. Combine with .sapx-section-lg for a prominent full-width band (e.g. a "Trusted By" or CTA section).

Generous Spacing

.sapx-section-lg

Maximum top/bottom padding, typically paired with .sapx-container-narrow for a centered, prose-style section such as an executive summary or closing statement.
